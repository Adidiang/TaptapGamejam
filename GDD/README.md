# GDD（策划文档）

本文件夹用于存放本项目的策划文档，是团队讨论玩法、确认需求的主要依据。

## 这里放什么

- 游戏设计文档（GDD）主文档，例如玩法概述、核心循环、系统设计
- 数值与关卡设计说明
- 需求说明、功能提案、评审记录
- 美术、剧情、音效等方向性文档
- 参考资料的收集与整理（可另建 `参考/` 子文件夹）

## 这里不放什么

- 配置表：请放到 `Config/` 文件夹
- 代码与工程文件：请放到对应的工程目录

## 文档约定

- 使用 Markdown 编写（`.md`），方便版本管理和差异对比
- 文档文件名尽量使用「中文名称_版本或日期」的形式，例如 `核心玩法_20260918.md`
- 大改版建议新建文件而不是覆盖旧文件，保留历史设计思路
- 文档中的关键结论（尤其是数值口径）要与 `Config/` 中的配置表保持一致
