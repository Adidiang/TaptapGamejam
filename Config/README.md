# Config（配置表）

本文件夹用于存放本项目的配置表，即由策划维护、程序读取的数据文件。

## 这里放什么

- 数值配置表，例如角色、怪物、道具、技能、掉落、关卡波次
- 文本配置表，例如界面文案、对话、多语言文本
- 全局参数表，例如平衡性常量、难度曲线参数
- 配置表的导出结果（如 CSV / JSON），以及导出工具或脚本

## 这里不放什么

- 策划文档与设计说明：请放到 `GDD/` 文件夹
- 程序逻辑代码：请放到对应的工程目录

## 配置约定

- 源表建议使用 `.xlsx` 或 `.csv`，导出文件统一使用 `.csv` 或 `.json`
- 第一行为字段名，字段名使用英文小写或下划线命名，便于程序直接读取
- 每张表保留唯一的 `id` 列，且全表不可重复
- 导出文件由源表生成，不要直接手改导出结果，避免被下一次导出覆盖
- 修改数值时同步更新 `GDD/` 中相关的设计说明
