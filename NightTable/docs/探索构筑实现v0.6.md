# 探索、构筑与遗物实现 v0.6

日期：2026-09-27。本文记录当前代码行为；前三份专项策划中的“尚未实现”描述已由本版实现说明更新。数值仍为试玩配置，未完成正式平衡。

## 如何体验

- 新轮回携带16张起始牌，自有牌组最少2张、最多20张。
- 地图按I或左上角“行囊”打开牌组与遗物页签。安全房间可移除卡牌，移除需要确认；锁房、对话和战斗期间只可查看。
- F进入事件或商店，事件可选择奖励、暂时离开或明确放弃；商店库存重访不刷新。获得卡牌可加入、替换或放弃，替换和扣款一次提交。
- 普通战斗进入即锁门，战前对话后开始打牌；战斗结束直接返回地图，不再进入旧永久升级/删牌奖励页。
- 事件房和商店不锁门。第一间右侧房间是战斗，之后一层安排质押点事件和商店；二层至少有一个普通卡牌或遗物奖励事件。

## 已接入的规则

自有抽牌堆每小局重新洗配置牌组，弃牌不回收。抽空后仍可停牌，继续摸牌改用共享公共牌堆。风险按双方各自本小局次数累计：10%、20%……最高80%；先判定公共爆掉，成功后再入场检查负荷及陷阱。满槽弃掉公共功能牌也消耗此次风险次数。公共模板49张，耗尽补充但不重置风险。公共卡不会带入探索牌组。

七种战斗遗物及三种关键遗物全部可获得。战斗接入上限/槽位修改、首张数字减负荷、低负荷停牌奖励、陷阱奖励、固定/百分比结算及齿轮窥牌。每小局次数重置，遗物保留。对方停牌保护和自己停牌后的陷阱仍遵循既有规则。

事件固定生成奖励内容，普通遗物不能重复获得，无合法遗物时转为20质押点。钥匙、齿轮和印记只从固定支线获得，不进普通商店池。商店卡牌15点、遗物40点；余额不足、已售罄、已拥有遗物不可购买。普通遭遇胜利奖励10质押点，失败无质押点奖励；这是为支撑首轮消费加入的暂定经济配置。质押点与既有对战生命质押分别保存，不相互扣除。

## 关键支线与结局

为在当前盒子地图中完整验证机关流程，支线暂放在出生房左侧翼，不替换主城堡的随机房间：铜钥匣 → 铜锁门 → 钟机房获得齿轮 → F启动钟机 → 隐藏梯子上楼 → 无名祭坛获得印记。名称沿用“地窖铜钥”，正式地窖场景接入时可调整这段布局。

铜锁门是实际门连接，未开门时可揭示对面房间，但不能通过；隐藏梯子启动前不参与迷雾揭示或移动。靠近机关会显示F提示或缺少遗物的提示。放弃支线奖励不会阻止普通Boss通关。

战胜最终Boss后，若已启动钟机且持有印记，可选择“归还姓名”结局；也可直接开始下一轮。结局目前是占位文字，正式剧情未填入。

## 模块

| 文件 | 职责 |
| --- | --- |
| `run_inventory.gd` | 本轮牌组/遗物/质押点、容量校验、原子交易 |
| `relic_catalog.gd` | 十个遗物定义与战斗钩子、结算加成 |
| `room_content.gd` | 固定种子的房型、奖励、商店库存及支线构建 |
| `run_screens.gd` | 行囊、事件、商店、取舍确认与换牌界面 |
| `castle_exploration.gd` | 分类型锁门、铜锁与隐藏梯子通行 |
| `load_duel.gd` | 自有/公共抽牌流程、风险与每小局状态 |
| `combat_passives.gd` | 卡牌与遗物合并结算、陷阱奖励通知 |
| `run_state.gd` | 探索交易合法性、遗物共享、结局条件 |

旧路线、52张永久牌库和旧道具代码仅保留历史测试兼容；当前菜单与城堡流程使用本轮系统，不改写旧永久存档。当前轮回依然只保存在内存，关闭程序不保留进行中的探索。美术、事件文案及结局均为占位。

## 验证

统一 `tests/smoke.gd` 包括旧对战回归、新UI流程和 `tests/progression_test.gd`：交易原子性、20张上限/2张下限、遗物叠加、公共风险与重置、100种子的关键支线、100局公共牌堆对战。截图模式新增事件、商店、行囊及铜锁支线画面，均不改玩家存档。
