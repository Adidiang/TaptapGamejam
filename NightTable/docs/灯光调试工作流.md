# 灯光调试工作流（UE 玩家视角）

## 概念映射：虚幻 → Godot

| 虚幻引擎 | Godot 对应物 |
|---|---|
| Persistent Level | 主场景（如 `level1_whitebox.tscn`） |
| Sublevel（子关卡） | 子场景 instance（如 `LightingEnv`） |
| Lighting Scenario | 多份灯光子场景，按需 instance/visible 切换 |
| Post Process Volume | `WorldEnvironment` 节点的 `Environment` 资源 |
| Auto Exposure | `Environment.exposure_*`（自动曝光） |
| Exposure / Color Grading | `Environment.adjustment_*`（亮度/对比度/饱和度） |
| Bloom | `Environment.glow_*` |
| Vignette | `Environment.vignette_*` |
| LUT | `Environment.color_correction`（贴 ColorCorrection LUT 贴图） |

**关键差别**：UE 的 Post Process Volume 是"放一个体积影响区域"，Godot 的
WorldEnvironment 是"影响整个视口"（每场景一个，多个时后添加的生效）。

## 灯光结构

```
scenes/lighting_env.tscn     ← 唯一的灯光+后处理定义（Single Source of Truth）
    ├── Env  (WorldEnvironment)  后处理全在这
    ├── Sun  (DirectionalLight3D) 主光
    └── Fill (DirectionalLight3D) 补光

被这两个场景 instance：
├── scenes/level1_whitebox.tscn  （游戏运行时，脚本 _build_lighting 动态 instance）
├── scenes/art_preview.tscn      （Blender 预览）
└── scenes/lighting_studio.tscn  （灯光调试工作室，独立打开）
```

改 `lighting_env.tscn` 一处，三个场景全部生效。

## 怎么调灯光（三种姿势）

### 姿势 1 · 编辑器里直接调（推荐，所见即所得）

1. 双击 FileSystem 里的 `scenes/lighting_studio.tscn` 打开
2. 场景里有测试模型（球/盒/胶囊/地板/墙板），影子和高光都能看到
3. 选中 `LightingEnv > Sun`，Inspector 里改 **Rotation**（角度）或 **Light Energy**（亮度）
4. 视口**实时刷新**，改完 Ctrl+S 保存
5. 跑 `level1_whitebox.tscn`（F6）确认游戏里的效果

### 姿势 2 · 运行时快捷键（游戏中微调，不用切场景）

跑 level1 后按：

| 按键 | 效果 |
|---|---|
| `F1` / `F2` | 亮度 −0.1 / +0.1（Environment.adjustment_brightness） |
| `F3` | 重置所有后处理到默认值 |
| `[` / `]` | 暗角强度 +0.05 / −0.05 |
| `-` / `=` | SSAO 强度 −0.2 / +0.2 |

画面左下角有黄色 HUD 实时显示当前值。

**注意**：运行时改的是 Environment 资源的**运行时副本**，不写回 .tscn。
调到满意后，把数值记下来，去 `lighting_env.tscn` 里改默认值固化。

### 姿势 3 · Blender 里调（不推荐做灯光，只做建模）

Blender 的灯光和 Godot 完全是两套体系，导出 glb 不会带 Godot 灯光节点。
Blender 里只建模型，灯光回 Godot 调。

## Environment 后处理字段速查（Inspector 路径）

选中 `LightingEnv > Env`，Inspector 里：

- **Tonemap** → Mode: Filmic（推荐）/ ACES（电影感更重）/ Linear
- **Auto Exposure**（曝光）
  - `Enabled`: 开关
  - `Scale`: 曝光倍率（>1 提亮，<1 压暗）
  - `Min/Max Sensitivity`: 自动曝光的ISO范围
- **Adjustments**（颜色调整，最常用）
  - `Brightness`: 亮度（1.0=原样，>1 提亮）
  - `Contrast`: 对比度（1.0=原样，>1 拉对比）
  - `Saturation`: 饱和度（1.0=原样，<1 偏灰，>1 鲜艳）
- **Glow**（辉光/Bloom）: 白盒建议关
- **Vignette**（暗角）: `Intensity` 0~1，0.4 是比较温和的
- **SSAO**（环境光遮蔽）: `Intensity` 2.5 左右，墙脚/门洞的接触暗部
- **Fog**（雾）: 需要氛围时开，白盒不建议
- **Depth of Field**（景深）: Compatibility 渲染器不支持，Future/Forward 才有

## 后处理性能提示（Compatibility 渲染器）

- SSAO 在 Compatibility（GLES3）渲染器支持 4.3+，开销中等
- Glow 开销中等，白盒阶段不必开
- Exposure 自动曝光需要每帧计算，关掉可以省一点
- Vignette 几乎零开销，可以常开

## 常见坑

1. **Sun 太亮把画面冲平**：ambient 和 sun 的光比要拉开（如 0.35 : 1.3），
   光比太小画面就是"白膜"
2. **墙脚没暗部**：SSAO 没开或 intensity 太低
3. **glb 模型在 Compatibility 渲染器下全员变黑**：glb 合并大 mesh 触发自阴影 bug，
   解法是 `cast_shadow = OFF`（见 `scripts/art_preview.gd`）
4. **运行时调了不生效**：确认 instance 的名字是 `LightingEnv`（脚本靠名字找）
5. **想让某关卡灯光不一样**：复制 `lighting_env.tscn` 改名（如 `lighting_env_boss.tscn`），
   在那个场景里换 instance 引用
