# 局内对战 v0.3

日期：2026-09-25。已实现可试玩版本，数值与功能效果为临时配置。

后续更新：功能牌已扩展为三类，当前牌组与结算规则以 [功能牌设计v0.4](功能牌设计v0.4.md) 为准。下文的五种功能牌配置和纯数字比较是0.3历史记录。

## 本版规则

- 双方从各自牌组抽两张，你先操作、对方后操作，首次操作不额外抽牌。
- 数字牌明置，功能牌占用三格槽位；自己的功能可查看说明，对手仅显示牌背，不显示其总负荷。
- 此后每回合开始选择摸一张或停牌。操作阶段可以使用任意多张可用功能牌，最后结束回合。
- 功能牌使用后移入本局弃牌区并释放负荷。所有弃牌本局不回收；下局重新洗完整牌组。
- 自己的操作阶段可主动弃掉任意功能牌，不触发效果，释放负荷和槽位；无需等待对方停牌，也不限次数。回合开始的摸牌/停牌选择阶段、对方回合、自己已停牌或本局结束后不能弃牌。电脑也可弃掉不再使用的功能牌。
- 负荷最多21，恰好21合法。摸牌后超过21立即判负，不能补救；数字点数总和没有21上限。
- 功能槽满时，新抽功能牌先弃掉，不计入负荷。不会替换已有功能牌。
- 停牌后本局不再行动且不能被对方影响；另一方可继续回合及使用自身效果。
- 双方停牌后比较数字总和。牌库抽空时，下次回合开始自动停牌。
- 电脑逐步自动行动，展示摸牌、功能牌使用和停牌记录，不读取玩家暗牌或牌顶。

## 临时牌组

为了保持局外牌库存档和加删牌流程，入场时将永久牌库转换为战斗牌组，不改写存档：A–9 对应数字1–9，负荷为数字除以2向上取整；10/J/Q/K 按点数和花色映射到下表功能牌。默认52张中36张数字牌、16张功能牌；对方使用同样的初始牌组。

| 功能 | 负荷 | 效果 |
| --- | --- | --- |
| 鼓舞 | 2 | 自己最大数字牌 +3 |
| 卸重 | 2 | 自己负荷最大的数字牌减负荷2，最低1 |
| 干扰 | 3 | 对方最大数字牌 -3，最低0；对方停牌后不可用 |
| 舍弃 | 1 | 移除自己最小数字牌并释放该牌负荷 |
| 预见 | 1 | 私下查看自己接下来的两张牌；摸牌后清除提示 |

本版自动选择效果目标，同值时选先入场的牌。没有合法目标时不能使用，也不会消耗该功能牌。使用记录公开，未使用功能牌的名称与负荷不公开。

## 与局外的衔接

地图、节点、商店、奖励、生命与永久存档流程保留。普通遭遇仍打三局、Boss一局，平局前两次重开、第三次按普通判胜/Boss判负处理；质押与生命结算沿用原框架。普通输局损失按当前在场牌数计算，1–3张一份基础注、4张两份、5张及以上三份，不随更多卡牌无限增长。

旧升级、遗物、道具仍保存在原流程，但本版不触发旧21点效果，入场页与规则页已说明。旧 Boss 特殊能力暂不参与新对战。黑杰克、A的1/11转换、五龙和爆牌回溯均不生效。后续设计确定后可通过单独的兼容层重新接入，避免改变局外存档。

## 模块与扩展入口

| 模块 | 职责与修改方式 |
| --- | --- |
| `scripts/combat_card.gd` | Resource卡牌定义，包含类型、数字、负荷、效果ID、参数和目标；可保存为.tres |
| `scripts/combat_catalog.gd` | 临时牌组工厂、槽位与负荷上限、旧牌库映射；同效果新牌只需配置新参数 |
| `scripts/combat_effects.gd` | 效果注册表及处理函数；新机制注册新ID，并补充合法目标检查 |
| `scripts/load_duel.gd` | 单局状态机与两方的牌堆、数字区、功能区、弃牌；统一验证回合、消耗和停牌保护 |
| `scripts/duel_encounter.gd` | 将单局结果接入旧质押、三局及奖励流程，不负责卡牌效果 |
| `scripts/duel_view.gd` | 纯显示和操作入口，数字区自动换行并可滚动，操作按钮保持在底部 |
| `scripts/main.gd` | 页面导航与电脑动作计时；切换页面后过期动作不会继续操作对局 |

卡牌定义与运行实例分开：战斗修改实例的数字/负荷，不修改共享资源或永久牌库。新功能效果先在效果注册表增加处理函数，再由卡牌定义引用；不要在界面中写效果逻辑。新牌组可直接向 LoadDuel.start 传入双方的 CombatCard 数组。

## 验证

统一入口仍为 tests/smoke.gd：包含新版200个种子的自动对战、边界与牌数守恒检查、普通/Boss结算、实际界面到奖励和商店流程，以及原有地图、存档与旧引擎回归。

`--smoke` 与 `--capture` 不读写玩家存档。截图模式暂停电脑计时以生成固定画面；正常启动时电脑自动行动。旧 blackjack_match.gd 仅保留回归参考，已不被实际游戏使用。
