## 一、核心理解

玩家在一轮探索中逐步配置自己的牌组，**最多20张**。牌少时，关键牌更容易在早期摸到；代价是自有抽牌堆更快耗尽，需要更早停牌，或者冒险使用公共牌堆。公共摸牌次数越多，直接爆掉的概率越高。

这里的“更少回合内拿下胜利”是构筑形成的压力，不设置额外的硬性回合倒计时。大牌组提供更多安全摸牌机会，但不保证胜利，仍受负荷上限、卡牌搭配和停牌时机约束。

术语区分：**一轮探索**是出生到最终结局；**一次遭遇**是一个房间战斗；**一小局**是重新发牌到判定一次胜负。“自有牌组”是探索中配置的卡牌清单；“自有抽牌堆”是它在当前小局洗牌后的剩余部分。现有数字区和功能槽仍是卡牌入场位置，不新增传统手牌区。

## 二、已确认规则

| 项目 | 新版规则 |
| --- | --- |
| 牌组容量 | 玩家自有牌组最多20张，数字牌与全部功能牌合并计数 |
| 探索中构筑 | 玩家可在本轮探索中调整自己的牌组，允许通过减少牌数提高关键牌上手概率 |
| 获得卡牌 | 未满时可加入或丢弃新牌；满20张时可替换一张现有牌，或丢弃新牌 |
| 自有牌耗尽 | 继续摸牌时转为使用公共牌堆，不能继续从自有牌堆摸牌 |
| 公共风险 | 每次使用公共牌堆都承担直接爆掉的概率，后续使用的概率越来越高 |
| 策略取舍 | 小牌组更集中但更早进入风险区；大牌组更耐用但关键牌可能更晚到手 |

卡牌只有数字牌和功能牌两大类；功能牌继续分效果、加成、陷阱。爆掉是公共摸牌的风险结果，暂不设计成第三类可持有的“炸弹牌”。

## 三、牌组配置与获得卡牌

以下为首版暂定：

- 允许在安全探索状态调整牌组：出生房、已完成房间、战斗结束后的奖励阶段。锁房待战、对话中和对战中不可修改，也不能在一次多小局遭遇的中途换牌。
- **最低2张，最高20张**，使开局两张都能来自自有牌组。最低数量未由玩家确认，若以后允许0或1张，需要另行确定开局公共摸牌风险规则。
- 可主动移除牌组中的牌，但不能减至最低数量以下。主动删牌首版不收费；移除前明确提示本轮失去该牌。
- 首版不设备用牌库，获得的牌只能加入当前牌组、替换或放弃。卡牌图鉴只用于查看，不是可随时重新取牌的库存。
- 允许同名牌多张，每一张都占一个名额；首版不另设同名数量上限。多张同名牌必须通过实际获得，不允许复制配置。
- 本轮构筑不写回账号永久牌库。旧存档中的永久加删牌与新版初始牌组如何迁移，留待实现时设计；不自动截取旧52张中的前20张。

获取流程：

| 当前牌数 | 可选操作 | 结果 |
| --- | --- | --- |
| 2–19张 | 加入新牌 | 当前数量+1 |
| 2–19张 | 用新牌替换一张旧牌 | 数量不变，便于保持精简牌组 |
| 20张 | 选择一张旧牌并确认替换 | 旧牌移除，新牌加入，始终保持20张 |
| 任意合法数量 | 放弃新牌 | 牌组不变 |

替换应作为一次完整操作提交，取消选择时保留原牌组，不能先删除旧牌再要求玩家完成操作。多张奖励逐张处理；离开奖励页面前要明确完成或放弃。

**战斗内弃牌不等于探索中删牌**：使用功能牌、主动弃掉功能牌、“舍弃”移除数字牌及满槽丢弃，都只影响当前小局的卡牌实例，不永久删除自有牌组中的卡牌。

## 四、公共牌堆与风险提案

### 抽牌来源

每小局将配置好的自有牌组完整洗牌，开局抽两张，后续每回合仍选择摸一张或停牌。自有抽牌堆有牌时必须抽自有牌，暂不允许提前选择公共牌堆。抽完最后一张自有牌本身不会进行公共风险判定；只有下一次实际选择摸牌才进入公共流程。

自有牌堆耗尽后依然可以选择停牌，**不会因为抽空而强制摸公共牌，也不再自动停牌**。使用过及弃掉的自有牌本小局不洗回。新小局（含平局重开）恢复完整自有牌组并重新洗牌。

### 谁共用、如何计数（暂定）

公共牌堆为双方共用的实际牌堆，双方自有牌耗尽后都从中摸牌。首版建议基础模板为36张数字牌（1–9各4张）和13张功能牌（当前每种各1张），共49张；这只是公共牌的组成，不是玩家初始牌组。

公共堆耗尽后按相同模板补充并洗牌，**不重置风险次数**。摸到的公共牌不加入探索中的自有牌组，小局结束后不带走，也不能借由补充公共堆回收自己之前弃掉的牌。

风险按**各方本小局自己的公共摸牌次数**独立累计，不按双方合计次数，也不跨小局累计。这样停牌的一方不会被另一方摸牌间接加风险。每小局双方从0次重新开始。

### 概率曲线（暂定数值）

建议第n次公共摸牌的直接爆掉概率为：**P(n)=min(10%×n, 80%)**。

| 本方本小局第几次公共摸牌 | 本次爆掉概率 |
| --- | --- |
| 1 | 10% |
| 2 | 20% |
| 3 | 30% |
| 4 | 40% |
| 5 | 50% |
| 6 | 60% |
| 7 | 70% |
| 8及以后 | 80% |

这是每次摸牌前的条件概率，不是累计概率；前3次均未爆掉的概率为0.9×0.8×0.7=50.4%。后期封顶80%是避免必死摸牌的首版提案，“是否一直涨至100%”仍可调整。界面必须显示下一次的实际概率，不能只写“危险”。

### 一次公共摸牌的处理顺序

1. 玩家在回合开始看到“自有牌0张、公共摸牌、本次爆掉概率”，仍可改选停牌。
2. 确认摸牌后，本方公共摸牌计数+1，按对应概率判定。
3. 若爆掉，**立即输掉当前小局**，不抽取公共牌、不进入操作阶段、不触发摸牌陷阱和入场遗物。整次遭遇是否失败、生命损失多少，沿用遭遇层规则；不是直接结束整轮探索。
4. 若未爆掉，从公共牌堆取一张，按数字牌或功能牌正常入场。满槽功能牌仍直接弃掉，但这次公共计数已消耗，不返还、不补抽。
5. 应用正常入场的负荷修正，再检查负荷上限。超过上限仍立即判负；公共风险判定成功不代表免疫超负荷。
6. 未超限才处理普通摸牌陷阱并进入操作阶段。后续使用、弃牌、停牌规则保持不变。

公共爆掉与负荷超限是两种独立败因。配重环等提高负荷上限的遗物不能降低公共爆掉概率；已设计遗物中没有免疫公共爆掉的效果。

## 五、与现有卡牌、遗物的衔接

- 数字牌点数、卡牌负荷1–5、基础负荷上限21、基础功能槽3个保持不变，遗物可按其描述修正上限和槽数。
- 公共牌成功入场后与自有牌规则相同：数字牌明置、功能牌暗置；陷阱、加成、减负荷效果正常适用。
- **预见暂定只看自有抽牌堆**，最多2张；不足则只看剩余，不跨到公共牌堆。自有牌堆为空时不可使用，可主动弃掉。不能预知公共风险随机结果。
- 停摆齿轮仍在初始发牌后只看自有牌库顶1张；只剩2张初始牌组时，发牌后无牌可看，效果为空。
- 磨损砝码等入场效果可以作用于成功入场的公共数字牌，但必须先通过公共风险判定；织线梭等奖励不能在爆掉之后补救。
- 停牌保护不变。主动弃牌不推进公共次数，效果牌的“使用次数”也不是公共摸牌次数。现有卡牌没有额外抽牌效果；以后新增时应统一走抽牌来源与风险流程，不能绕过公共风险。
- 首版暂定敌人同样遵守20张上限和公共风险，可按敌人类型配置不同牌组。AI只能利用可见局面、自己的牌及公开风险，不读取随机结果或未公开公共牌序。

## 六、首版初始牌组建议（暂定）

建议从16张开始，保留4个加牌空间；不用开局就装满20张。下面仅作为试玩配方，之后需要验证实际对战节奏：

| 类别 | 内容 | 数量 |
| --- | --- | --- |
| 数字牌 | 数字2、3、4、5、6各2张 | 10 |
| 效果牌 | 鼓舞、卸重、舍弃、预见各1张 | 4 |
| 加成牌 | 底气1张 | 1 |
| 陷阱牌 | 绊索1张 | 1 |
| 合计 | 数字10张、功能6张 | 16 |

例如6张自有牌组开局发2张后，还能安全地从自己的牌堆摸4次；下一次摸牌才承担10%的公共风险。这里“安全”仅指没有公共爆掉判定，摸自有牌依然可能负荷超限。

最小2张牌组能稳定拿到指定两张，但第三张起就来自公共牌堆，并不能稳定循环这两张牌。若测试发现极小牌组明显强于其他构筑，优先调整最低牌数、初始公共概率和公共牌组成；不在文案中隐瞒或临时改变概率。

## 七、界面、实现范围与待确认

牌组界面显示“当前张数 / 20”、数字/功能数量和各卡负荷，支持查看、移除、替换。新卡获取窗口要并列展示新旧牌，明确“丢弃新牌”与“删除自有牌”的区别。

战斗摸牌按钮区分“抽自有牌（剩余N张）”与“抽公共牌（爆掉概率X%）”，同时保留停牌按钮。风险次数与概率公开，公共牌序隐藏；日志区分公共爆掉、负荷超限与正常点数结算。

后续实现应分离：本轮牌组清单、当前小局自有抽牌堆、双方共享公共牌堆、各方公共计数、入场卡牌实例。风险随机源应支持固定种子，便于复现。战斗结束只恢复配置牌组，不把公共牌或战斗属性修改写入构筑。

仍待确认的首版提案：最低2张；安全房间免费删牌且无备用库存；16张初始牌组；公共堆双方共享但风险独立计数；每小局风险重置；10%起步每次+10个百分点封顶80%；公共模板组成及补充方式；敌人采用相同规则。以上均非已实现内容。

验证重点：20张容量与原子替换、删牌最低限制、最后一张自有牌不误触发风险、空堆仍可停牌、公共爆掉优先于入场效果、满槽弃牌仍累计次数、双方计数独立、小局重开恢复牌组和风险、公共卡不永久入组，以及极小牌组是否产生优势过强的固定打法。
